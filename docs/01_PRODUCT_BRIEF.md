# OxyArea — Product Brief

## Vision

Make private WordPress client areas as easy to create as a contact form.

A common WordPress implementation currently combines several products:

- role editor;
- frontend login/profile plugin;
- login redirect plugin;
- content restriction plugin;
- client portal/private page plugin;
- secure download plugin;
- custom PHP.

OxyArea unifies the workflow.

## Positioning

> **Private areas, not memberships.**

Do not position the product as another MemberPress / Ultimate Member clone.

OxyArea is aimed at:
- agencies;
- software houses;
- SMEs;
- professional firms;
- distributors/agents;
- associations;
- WooCommerce stores needing richer private dashboards.

## Jobs to be done

- “Different roles need different dashboards.”
- “This exact customer must see only their own information.”
- “Everyone from ACME SRL needs shared company documents.”
- “After login, users must be sent to the correct portal.”
- “Private files must actually be private.”
- “I don't want five plugins for one private area.”

## Product principles

1. Secure by default.
2. One dashboard template can serve thousands of users.
3. No manually created page per customer.
4. Role identifies **type of user**.
5. Company/group identifies **organization/account**.
6. User assignment identifies **individual ownership**.
7. Native WordPress APIs first.
8. Extensible core.
9. No vendor lock-in for customer data.
10. FREE is useful; PRO adds advanced business value.

## Out of scope

Core product is not:
- LMS;
- social network;
- forum;
- subscription billing platform;
- Stripe/PayPal membership engine;
- CRM;
- helpdesk;
- gamification tool.

Integrations may come later.
